# Packing Co. — Website

Static website prototype for a professional packing services business.

## Project structure

```text
packing-project-v4/
├── index.html              # Page structure and content
├── css/
│   ├── styles.css          # Base styles, layout, components and responsive rules
│   └── animations.css      # Motion system and Before/After reveal styles
├── js/
│   ├── main.js             # Navigation, scroll effects, section reveals and form demo
│   └── reveal.js            # Interactive Before → Packed image switch
├── assets/
│   ├── images/             # Place local/licensed project images here
│   └── icons/              # Place favicon/icon assets here
└── README.md
```

## Important

The current prototype uses external image URLs as temporary visual assets. Before production, replace them with images owned by the client or properly licensed images and update the URLs in the HTML/CSS.

The quote form is still a demo and needs to be connected to the client's preferred email, CRM, WhatsApp or form service.
